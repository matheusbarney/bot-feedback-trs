# Glossário — Bot Feedback TRS / IACP

Termos do domínio do projeto que o whisper.cpp (transcrição local de áudio)
costuma errar. Usado pela skill `/corrigir-transcricao` como referência para
corrigir as transcrições antes delas ficarem valendo.

Isto é um documento vivo: toda vez que a skill encontrar um erro de
transcrição que se repete e não está listado aqui, ela deve propor adicionar
uma entrada nova, não só corrigir e seguir em frente.

## Ferramentas e tecnologia

| Termo correto | Erros comuns de transcrição |
|---|---|
| Whisper.cpp | Weasper.CPP, Wisper CPP, Whisper C++ |
| OpenWhispr | Open Weasper, Open Whisper, Open Wispr |
| Claude Code | Cloud Code, Clod Code |
| GraphRAG | Graph Rag, Graf RAG |
| MAPEAR | Mapear (ok, mas confirmar maiúsculas quando for o nome do sistema) |
| GERAIA | Geraia, Jeraia |

## Siglas e sistemas do governo/CIn

| Termo correto | Erros comuns de transcrição |
|---|---|
| e-Fisco | e-Físico, E Fisco, EFisco |
| CATMAT | Cat Mat, Catmát |
| GGAFP | G G A F P, Gi Gafpi |
| SETD | S E T D, Cetd |
| ATI-PE | A T I P E, Atipê |
| SEI | Essei (quando não for a sigla de processo eletrônico) |
| SGC | S G C |
| PE Integrado | P E Integrado |
| CIn | SIM (ver nota abaixo — é o erro mais importante do glossário) |

**Nota importante sobre "CIn" vs "SIM":** nas atas de reunião, "CIn" (Centro
de Informática da UFPE) foi transcrito repetidamente como "SIM" — são sons
parecidos em português. Qualquer menção a "servidor do SIM", "infraestrutura
do SIM" etc. em transcrições novas deve ser tratada como candidato forte a
"CIn", e não como a sigla de outro sistema.
